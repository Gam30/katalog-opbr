Konfigurasi Firebase Real-Time

Cara Menghubungkan Database Gratis (Tanpa Kartu Kredit):

  1. Buka console.firebase.google.com → klik Add project.
  2. Buka menu Build → Firestore Database → klik Create database (pilih mode Test mode / sesuaikan Rules).
  3. Buka menu Build → Authentication → Sign-in method → aktifkan Anonymous.
  4. Buka Project Settings (ikon roda gigi) → General → Your apps → Web (</>), lalu salin objek firebaseConfig di bawah ini.

Tips: Klik Download index.html Siap Hosting agar kode firebaseConfig tertanam permanen di dalam file HTML sebelum kamu upload ke Vercel, Netlify, atau GitHub Pages.
